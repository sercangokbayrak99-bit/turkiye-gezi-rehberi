# Türkiye Gezi Rehberi

Türkiye'nin 81 ilini; ilçeleri, tarihî mirası, doğası, mutfağı ve günlük yaşam bilgileriyle tek mobil uygulamada buluşturmayı hedefleyen React Native / Expo projesi.

## İlk sürüm

- Profesyonel mobil ana ekran ve tasarım sistemi
- Bursa örnek şehir profili
- Kategori ve metin araması
- Kalıcı favoriler
- Mekân detay ekranı
- Google Maps yol tarifi
- 81 ile genişleyebilen veri modeli
- Android paket kimliği: `com.sercangokbayrak.turkiyerehberi`

## Çalıştırma

```bash
pnpm install
pnpm start
```

Tür kontrolü:

```bash
pnpm typecheck
```

## Yol haritası

1. Bursa'nın 17 ilçesini eksiksiz veri setine dönüştürmek
2. Harita ve konuma göre yakındakiler
3. Çevrimdışı şehir paketleri
4. İçerik yönetim paneli ve veri tabanı
5. Marmara Bölgesi, ardından 81 il
6. Google Play mağaza paketi, gizlilik politikası ve kapalı test
